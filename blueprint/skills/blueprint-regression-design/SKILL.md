# 缺陷与回归设计；在对应验证或交付场景下使用。

先在修复前证明最小测试会失败，再验证修复后通过；若无法运行旧版本，清楚说明证据限制。
围绕触发条件的相邻边界设计少量有意义的用例，覆盖空输入、重复、取消、断线或历史恢复中适用的部分。保存日志与错误码，区分 flaky 现象与稳定回归。

执行前调用平台提供的 ensure_role_environment，核对本节点真实执行环境。缺项先准备并复核；安装失败或能力不兼容应返回具体证据，不把注册视为已加载。遵守平台工作区、权限和交付协议。
